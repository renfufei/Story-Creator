## 一、为什么重排

高中 11 册（必修1-5 / 选修6-11）原来的「主题」**连名字都没有**，就叫 `Unit 1` ~ `Unit 5` ——
是课本单元编号，不是分类。一个 Unit 50~80 词，段内词汇毫无关联，例如选修8 `Unit 1`（75 词）里同时装着：

- 人口与社会 `immigrant` / `racial` / `Hispanic`　·　政治 `elect` / `federal` / `socialism`
- 地理 `strait` / `pole` / `Arctic`　·　交通 `cable car` / `tram` / `ferry` / `brake`
- 思辨 `illustrate` / `distinct` / `indicate`　·　动物 `seagull`　·　情绪 `miserable`

切关后这个 Unit 会变成连续 12 关，关与关之间没有任何语义关联。

按同样的判据重排：把本域的词随机抽 6 个放进一关，玩家会不会觉得「这 6 个是一伙」；
归类**主要按含义**，同时允许**按前缀/词根聚类**（例：`study` / `student` 同类）。
