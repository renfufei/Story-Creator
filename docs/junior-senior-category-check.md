# 初中 / 高中词库类目核对报告（对照同一份 16 个常见主题词）

> 检查范围：初中 **5 册**（七上 ~ 九全）· **250 主题** · **2309 词** · **444 关**；
> 高中 **11 册**（必修 1~5 / 选修 6~11）· **406 主题** · **3877 词** · **736 关**。
> 对照清单（与小学同一份）：月份、季节、日期时间、颜色、天气、星期、餐具、蔬菜、食物、文具、学习用品、饮料、动物、衣服、身体部位、水果。
> 数据源：`src/main/resources/learn/pep-words.json`；域定义：`junior-semantic-domains.tsv`（48 域）/ `senior-semantic-domains.tsv`（41 域）。
> 日期：2026-10-10。

---

## 摘要（结论先行）

**初中、高中与小学的情况完全不同：不存在「归位」问题，也不需要像小学那样做拆分。**

1. **16 类目全部有对应的语义域**（初中）或**对应域/就近归属**（高中），**没有一类完全缺失**。
   - 初中：`月份/星期/日期时间` → **时间与日期**；`颜色` → **颜色与形状**；`天气/季节` → **天气与季节**；
     `餐具` → **厨房与餐具**；`蔬菜/水果` → **水果与蔬菜**；`食物/饮料` → **食物与饮料**；
     `文具/学习用品` → **学习用品**；`动物` → **动物世界**；`衣服` → **服装与配饰**；`身体部位` → **身体与健康**。
   - 高中：域池较小（41 域），部分类目**无独立域**（天气/季节/餐具/蔬菜/水果/饮料/文具），词就近并入 `自然与地理` / `家居与住所` / `食物与饮料` / `学习用品` 相关域。
2. **没有发现任何「真错位」**。扫描出的全部「疑似错位」都是**同形异义**（英文同形而中文释义完全是另一个义项），例如 `orange=橙子`（非颜色）、`second=第二`（非秒/时间）、`dress=穿衣服`（非连衣裙）、`milk=挤奶`（非牛奶）、`zoo=动物园`（非动物）、`fall=摔倒`（非秋天）、`light=灯`（非浅色）、`silk=丝绸`（非衣服）、`present=礼物`（非现在）、`button=按钮`（非纽扣）、`bear=忍受`（非熊）、`march=行军`（非三月）。**这些词当前所在域是对的，动了反而错。**
3. **最关键的硬约束：这 16 个类目在初/高中无法像小学那样拆成独立域——一拆就丢词。**
   原因是教材把同一类目的词**分散在多册多单元**（小学则集中在单册单单元）。而 `WordMatchBank.load()` 对
   「某册某主题 < 3 词」一律 `log.warn + continue`，**整个主题连同词一起丢弃**（源码 `WordMatchBank.java:152-156`）。
   实测（见第五节）：初中若把 16 类目全拆为独立域，**至少丢 28 词**；高中更甚，几乎每个类目在多数册都不足 3 词。
4. 因此本报告的**建议是：初/高中保持现状**（合并域设计是当前词量分布下的唯一零丢失解）。
   **未做任何数据改动**，未重建词库、未动下游。

## 三、逐类目核对（「疑似错位」全部证伪）

> 方法：用扩充关键词表扫描全词库，对每个命中的词检查「现属域」，再人工判定**词义**。

### 初中

- **月份**：13 词全在 `时间与日期`（七上）✓。命中 `may=可能，也许` 在 `常用功能词（代词/冠词/助动词）`——**助动词义，正确不动**。
- **星期**：8 词在 `时间与日期` ✓（`Monday`~`Sunday` + `weekday`）。`weekend=周末` 在特殊主题 `同义表达：周末、人`（特殊主题，保留）。

## 四、为什么小学能拆、初高中不能拆（根因）

| | 小学 | 初中 / 高中 |
|---|---|---|
| 类目词的教材分布 | **集中在单册单单元**（月份全在五下、颜色全在三上、身体部位全在三上） | **分散在多册多单元**（季节词跨 4 册每册 1~2 个；高中更甚） |
| 拆独立域后每册词数 | 天然 ≥3（如一册 12 个月份词） | 多数册 **1~2 词 → <3** |
| `WordMatchBank` 后果 | 不会丢词 | **整个主题被丢弃，词一起丢** |
| 结论 | **可归位**（已落地：161→163 关） | **不可拆**（只能维持合并域） |

> 一句话：**小学的问题是「分类没建」，初高中的问题是「分类建得太细也不够词」——两个问题方向相反。**

## 五、拆域代价实测（若强行拆分）

> 口径：把某类目的词从现有合并域**移出**为独立域；若该册该类目 <3 词，则该主题被丢弃 → 词丢失。
> 下表为**下限估计**（按类目词计，未含跨类目重复）。

### 初中（16 类目全部独立化的代价）

| 类目 | 会出现 <3 词的册 | 丢词数 |
|---|---|---|
| 季节 | 七下/八上/八下/九全 全部 | 5 |
| 颜色 | 七下、九全 | 3 |
| 餐具 | 七下(2)、八下(1) | 3 |
| 天气 | 八下(2)、九全(1) | 3 |
| 衣服 | 七下(2)、八下(2) | 4 |
| 饮料 | 七上(1)、八上(1) | 2 |
| 水果 | 九全(2) | 2 |
| 星期 / 日期时间 / 蔬菜 / 文具 / 学习用品 / 身体部位 | 各 1 册 1~2 词 | 各 1 |
| **合计** | | **≥28 词** |

**仅** 月份（13，全在七上）、食物（30）、动物（28）三类可无痛独立。

### 高中（几乎全丢）

- 颜色(1)、季节(1)、天气(3)、餐具(3)、文具(3)、学习用品(3)、水果(5)、日期时间(3)、蔬菜(9)——
  **每一个类目都在多数册不足 3 词**，独立化后 **≥ 60% 的类目词会被丢弃**。
- 无任何类目能在「全册 ≥3 词」条件下独立。

## 六、结论与建议

1. **16 类目在初中 / 高中均已妥善归位**——凡是词义确属该类目的词，都在语义最贴近的域里；没有真错位、没有遗落。
2. **「拆成独立类目域」在当前词量分布下不可行**（会丢词），且会破坏上一轮已建立的**跨册统一域**体系（同一类目在不同册落不同域，反而不一致）。
3. **建议：初/高中保持现状**。本次检查**未改动任何数据**。

### 如仍希望进一步优化，可考虑（均有代价，需你拍板）

- **方案 A（推荐）**：不动。
- **方案 B**：只把 **初中七上的 `月份`(13) / `星期`(7)** 从 `时间与日期` 拆为独立域——这两类在七上本就密集，且课本就是独立单元。代价：与其余册的「跨册统一域」口径不一致（七上叫 `月份`，其他册无此域）。
- **方案 C**：全量强制拆分——**接受丢词**（初中 ≥28 词，高中 ≥60% 类目词）。不建议。
