# 初中词库 · 逐关校对报告（2026-10-09）

> **一句话**：把七~九年级 5 册的 **444 关**逐关摊开读一遍，标出与同关其他词不搭的 **96 个词**；
> 能挪的挪走 **75 条**，挪了会更糟的保留原位 **21 条**，另为「让目标域站得住脚」补 **6 条移动**。
> 结果：**81 条词换了归属**（59 条换语义域 + 22 条进特殊主题），词数**一条不变**，初中关数 439 → **444**。

上游是 `docs/junior-domain-taxonomy.md`（把初中从「课文顺序切段」重分类成 48 个跨册统一语义域）。
本页是它的**第二轮修补**：域已经分好了，但个别关里仍混着不搭的词。

## 一、为什么要第二轮

语义域是**按词**归类的，关卡是**按域切**的（`splitBalanced`，MIN 3 / MAX 7 / TARGET 6）。
所以「域分对了」不等于「关看起来顺」——一个域里只要混进 1 个语义跑偏的词，
它就会跟着这个域一起被切进某一关，和 5 个不搭的同伴摆在一起。典型：

- **专名混进泛称**：九全「人物与称谓」里塞了 18 个具体人名（`Picasso` / `George Crum` …），
  和 `pal` / `lady` / `kid` 这些泛称同关；
- **不定代词混进人物**：`nobody` / `somebody` / `anybody` / `none`；
- **方式副词混进性格**：`quietly` / `carefully` / `seriously` 和「诚实 / 勇敢」这种长期性情同关；
- **语言名混进国家**：`French` / `German` 与 `America` / `China` 同关；
- **动词混进名词域**：`finish` / `start` / `waste` / `fit` /`glue`；
- **固定短语混进名词域**：`get on well` / `run out` / `cut out` / `take after`。

## 二、判据与纪律

判据只有一句，和四六级那套一致：

> **把这一关的 6 个词随机摆在一起，玩家会不会觉得「这 6 个是一伙的」？**

纪律（写死在给子代理的 `SPEC.md` 里）：

1. **只标确实不搭的**，每册 10~40 条；**绝不为凑数而标**；
2. **零丢失**：一个词都不能凭空消失（词数必须一条不差）；
3. **不许自创域名**——去向必须是那 48 个域之一或既有特殊主题；
4. 同一册内**中文不得重复**（「同义表达：」类主题豁免）。

## 三、方法：5 个并行子代理

1. 用 `scripts/learn/` 的切关复刻把每册逐关摊平，生成 5 份校对材料
   （`pep-7-1.md` ~ `pep-9-1.md`，每行就是线上棋盘那一关）；
2. **5 个子代理并行**，一册一个，逐关读、逐条标，输出 `flag-<册>.tsv`；
3. 收集 **96 条**标记，逐条核对「字段与材料逐字符一致」（`NF==7`）；
4. 模拟全部移动，暴露出 **16 处「目标域会掉到 3 词以下」** 的陷阱；
5. 按「目标域落地后必须 ≥3 词」这条硬约束，分成**采纳 / 补位 / 放弃**三类，写回域表与词库。
