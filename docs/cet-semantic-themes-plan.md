# 四六级词库语义重组方案（已实施）

> 目标：把「大学」词源（四级 / 六级）的关卡从「按词性粗分」改成「按语义域归类」，
> 让**同一关的词语义相关、主题名有意义**（对齐人教版 PEP 的语义主题风格）。

## 一、现状诊断（改造前）

词库文件 `src/main/resources/learn/cet-words.json`，由 `scripts/learn/build_cet_words.py` 生成。
改造前的分类逻辑是 `theme_of(zh)`：**只看释义开头的词性标记**（`n.` / `v.` / `adj.` …）。

| 册 | 主题（关）数 | 词数 | 主题名分布 |
|---|---|---|---|
| cet-4 | 1251 | 7508 | 名词 613 关 / 动词 300 / 形容词 261 / 副词 48 / 其他 29 |
| cet-6 | 942 | 5651 | 名词 422 关 / 动词 273 / 形容词 214 / 副词 23 / 其他 10 |

**问题**：主题名只有 5 种，且「名词」一个名字挂 613 关；
每关的 6 个词只是**源顺序硬切**，彼此毫无关联
（例：`chair / procession / back / jacket / rifle / our` 被切进同一关）。

> **特殊类别**是兜底域：**一个域都不命中、或释义含糊/残缺/哪个域都只是勉强沾边**的词条一律进这里，
> 不硬塞进某个不贴切的域。

> **关键设计**：把上一版过大的抽象域拆开（`评价与判断` → 重要性 / 优劣评价 / 正确与错误；
> `社会互动` → 帮助与合作 / 竞争与冲突 / 控制与影响 / 交往与联系；
> `情感与心理` → 情绪与感受 / 性格与品质 / 态度与意愿），
> 否则「性质与状态」这类域会重演「名词 613 关」的老问题。

## 四、执行记录（已完成）

1. **词条去重**：全量 13159 条中，唯一 `(英文, 释义)` 组合只有 **11634** 条 —— 只对唯一组合分类，
   再回填到全部出现位置（同一组合必然同域，跨册也一致）。
2. **分批分类**：按英文词字母序切成 24 批（每批 500 条，同词的不同义项落在同一批以保证一致），
   每批逐条归入 68 域之一，输出 `序号<TAB>语义域`。
3. **零偏差校验**：每批**行数**、**序号序列**（逐行比对，非仅集合）、**域名白名单**三项全检，
   24 批全部通过（无跳过、无合并、无改写，非法域名 0）。
4. **分类结果落库**：写入 `src/test/resources/learn/cet-words-source/cet-themes.tsv`
   （`英文<TAB>释义<TAB>语义域`，11634 行），作为主题归属的**唯一真相**，构建可复现。
5. **重建关卡**：`build_cet_words.py` 改为按语义域分桶，**域内按源顺序切关**，
   每关 3~7 对（目标 6）；同一域多关时主题名加序号（如 `情绪与感受 · 3`）；
   不足 3 对的碎域（`短语与搭配` 各册仅 1 条）并入「特殊类别」，**绝不丢词**。

## 八、关卡顺序交错（2026-09-27）

**问题**：语义域切好之后，关卡是**按域整段连着排**的 —— 四级开头先连着 51 关「人物与身份」，
接着 84 关「性质与特征」（最长同类连排 84 关，六级 73 关）。一次做几十关同类词，**容易疲劳**。

**要求**：同一语义域**最多连排 5 关**，其余互相穿插。

**做法**（`build_cet_words.py` 的 `interleave_blocks`，`MAX_SAME_DOMAIN_RUN = 5`）：
把每个域的关卡切成**最多 5 关一块**，再排块的顺序 ——

1. **首轮**：按 `DOMAIN_ORDER`（具体 → 抽象 → 兜底）让每个域先各出一块，玩家早点见到每一类；
2. **其余**：按各域**剩余块数**加权做**平滑加权轮转**（SWRR，nginx 那套），块数多的域出现更频繁，
   各域几乎同时收尾。

**为什么不选另外两种更简单的排法**（都实测过）：

| 排法 | 结果 |
|---|---|
| 保持原样（按域整段） | 最长同类连排 **84 / 73** 关 —— 就是本次要解决的问题 |
| 每域取 5 关简单轮流 | 小域早早做完，大域剩余关卡全堆册尾 ⇒ 尾部最长连排 **34 / 38** 关，反而更糟 |
| 每次只取 1 关最公平（stride） | 最长连排仅 1~2 关，但**彻底打散**，同类词不再成块，失去「同类一起学」的编排意图 |
| **块级 SWRR（采用）** | 最长连排**恰为 5**；前 200 关覆盖 42 / 45 个域；各域同时收尾 |

**只改顺序，一个词都没动**：关卡集合、词条多重集、域内顺序、每域关头序号（`域 · N`）全部保持，
构建后逐项比对通过（纯置换）。

| 项 | 前 | 后 |
|---|---|---|
| cet-4 / cet-6 关数 | 1255 / 944 | **不变** |
| 词数 | 7508 / 5651 | **不变** |
| 源清单 `cet-4.txt` / `cet-6.txt` | — | **md5 不变** |
| 最长同类连排 | 84 / 73 关 | **5 / 5 关** |
| 同词两次出现间距中位数 | 10 / 8 关 | **496 / 394 关**（重排把重复词摊得更开） |
| 域最晚首次出现 | — | 第 319 / 303 关（共 1255 / 944 关） |
| 进度指纹 | `v1-` | **`v2-`** —— 关数词数都没变，光看数字识别不出顺序已变，必须升版本作废旧进度 |

**回归防线**：`CetWordBankTest.sameDomainNeverRunsLongerThanFiveLevels` 硬断言「同类连排 ≤ 5」
且「域的出现段数明显多于域数」（防止以后又退化成整段排）；构建脚本自身也会在**可避免的超限**时
直接 `SystemExit`、不出成品 —— 只有「某个域的关卡比其余全部加起来还多」这种数据偏斜才只告警
（那时连排躲不开，不该阻断构建）。

> 本节数值是**首次交错时**（域数 67）的实测值。同日稍后又做了第九节的细分化，域数与关数都变大了，
> 最新数值见第九节表格；「段数 > 域数 × 3」这条断言也在那时放宽为 **× 1.5**
> —— 域数从 67 涨到 130 后 × 3 过严（实测 303 段 / 130 域、243 段 / 130 域）。

## 九、大域细分化（2026-09-27，同日第二改）

**问题**：68 个域里有 35 个**装得太多**，同一关的词依旧不太相干。

最刺眼的是「性质与特征」——818 条，从 `able` 到 `awkward` 什么形容词都有：

```
ability / able / abnormal / abrupt / abstract / accessible / accidental / accountable /
accustomed / active / actual / acute / adjustable / advanced / alien / ambiguous /
anonymous / apparent / appearance / applicable / artificial / authentic / authoritative /
automatic / available / average / awkward …
```

6 条随机抽出来（比如 `acute / alien / available / average / artificial / accustomed`）
彼此毫无关系，玩家记不住，也起不到「同类词一起记」的效果。

**分布极偏**：最粗的 20 个域装走了 55% 的词条，尾部却有十几个域只有 20~40 条。

| 粗域 | 词条数 | 粗域 | 词条数 |
|---|---|---|---|
| 性质与特征 | 818 | 数量与度量 | 297 |
| 语言与交流 | 452 | 日常用品与工具 | 282 |
| 人物与身份 | 430 | 时间与频率 | 278 |
| 操作与处理 | 373 | 态度与意愿 | 271 |
| 身体与健康 | 362 | 性格与品质 | 265 |
| 情绪与感受 | 355 | 关系与异同 | 256 |
| 状态与情况 | 318 | 变化与发展 | 252 |
| 移动与位移 | 308 | 空间与方位 | 242 |

**粒度标准**：每个细域 **60~130 条**（约 10~22 关），**硬上限 150 条**（≈25 关）；
细域尽量 ≥ 20 条，天然稀少的词类（感叹词、序数词）可以到 5 条。

**做法**：把 35 个超过 150 条的粗域分成 8 组，并行细分成 **98 个小分类**
（拆分数 ≈ `round(行数/95)`，并夹在「不超过 150 条」与「不少于 45 条」之间）。
另 33 个没超阈值的域**保持原样**。粗域本身降级为**父域**（保留在树里，作为分组与兜底依据）。

拆分只按**词义所指的东西**分，不按词性、难度、词频；**不跨父域**（一个词不会从「性质与特征」
被挪到别的父域去）。

**数据文件**：

| 文件 | 作用 |
|---|---|
| `src/test/resources/learn/cet-words-source/cet-domain-tree.tsv` | **新增**。`父域<TAB>细域<TAB>说明`，131 行。行序即册内域的出现顺序；`说明` 一句话讲清收什么词 |
| `src/test/resources/learn/cet-words-source/cet-themes.tsv` | 第 3 列由「粗域」改写成「细域」；英文与释义**逐字节未动**，行多重集未动 |

**碎域兜底规则**（`build_cet_words.py`）：不足 `MIN_PAIRS = 3` 条的细域，先并进**同父域下最大的
兄弟细域**（语义最近），父域只有一个细域时才落到兜底细域（`特殊类别` 父域的第一个细域
`名物与事务`）。当前只有 `短语与搭配`（2 条）会触发。

**抽检**：拆分前「性质与特征」随便一关都是杂的，现在同一个细域里的词是真的同类 ——

| 细域 | 关内单词（示例） |
|---|---|
| 感官与色彩 | `dim / pale / vivid / transparent / gloomy / bright` |
| 难易与繁简 | `awkward / complex / simple / effortless / intricate / straightforward` |
| 疾病症状 | `fever / cough / plague / symptom / disability / malnutrition` |

**质量校验**（全部通过）：

1. **词条零变化**：`cet-themes.tsv` 改写前后，(英文, 释义) 多重集完全相等、逐行英文释义逐字节相同，
   只有 9198 行的第 3 列变了（正是那 35 个粗域的词条），其余 2436 行的域一字未动。
2. **不跨父域**：每个词的细域反查父域，与原粗域逐行一致，0 处越界。
3. **规模**：131 个细域全部在 30~149 条之间，无超 150、无 1~2 条的碎细域。
4. **域清单唯一**：细域全局唯一，不与原 68 个域名撞名。
5. **构建产物**：`cet-words.json` 词条多重集 == 源清单（7508 / 5651），
   每关 3~7 对、关内英文不重复。
6. **三副本一致**：服务 JSON ↔ 源清单 ↔ 小程序快照，26 册 / 3452 关 / 20191 词全对；
   人教版 3 个快照文件**逐字节不变**（反向证明没误伤）。

**回归防线（新增）**：

- `CetWordBankTest.domainsAreFinelyGrained`：每个细域在册内 **≤ 150 条词**，且用到的域 ≥ 120 个
  —— 粒度再退化成「一个域装几百条」会立刻红。
- `CetWordBankTest.fallbackBucketStaysSmall`：`特殊类别` 系词条占比 **< 3%**
  —— 兜底域一旦变大，说明分类在失效（词没地方去），细分多少个小分类都没意义。
- `CetWordBankTest.levels_areGroupedBySemanticDomain`：期望的域集合不再写死，
  改成**从 `cet-themes.tsv` 现算**，词库改了测试跟着走。
- `scripts/check_word_match.mjs`：域清单也从细域树现读（不再硬编码 68 个名字），
  并新增「每个细域 ≤ 150 条词、域数 ≥ 120」的线上断言。
