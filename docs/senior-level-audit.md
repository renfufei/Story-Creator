# 高中词库 · 逐关校对报告（2026-10-10）

> **一句话**：把高中 11 册（必修1~5 / 选修6~11）的 **731 关**逐关摊开读一遍，标出与同关其他词不搭的 **197 个词**；
> 能挪的挪走 **151 条**，挪了会更糟的保留原位 **46 条**，另为「让目标域站得住脚」补 **11 条移动**。
> 结果：**162 条词换了归属**（118 条进专有名词主题 + 44 条换语义域），词数**一条不变**，高中关数 731 → **736**。

上游是 `docs/senior-domain-taxonomy.md`（把高中从「课本单元 `Unit 1`~`Unit 5`」重分类成 41 个跨学段统一语义域）。
本页是它的**第二轮修补**：域已经分好了，但个别关里仍混着不搭的词。
这是初中同款修补（见 `docs/junior-level-audit.md`）的**放大版**。

## 一、为什么要第二轮

语义域是**按词**归类的，关卡是**按域切**的（`splitBalanced`，MIN 3 / MAX 7 / TARGET 6）。
所以「域分对了」不等于「关看起来顺」——一个域里只要混进 1 个语义跑偏的词，
它就会跟着这个域一起被切进某一关，和 5 个不搭的同伴摆在一起。高中最典型的三种：

- **专名混进泛称（本册最大宗，118 条）**：具体人名 / 作品角色名 / 机构名 / 作品名混在「人物与称谓」
  这类泛称域里 —— 选修10 的「人物与称谓」**33 词里 29 个是人名**，泛称只剩 4 个；
  选修11 更极端：17 词里 14 个是《奥德赛》角色 + 作家名。
- **跨域错位**：`spear`（矛）在「社会与法律」、`mud` / `liquid` 被堆在「自然与地理」的山川地貌里、
  `compass`（指南针）在「方位与位置」、`shave`（刮）在「家居与住所」。
- **兜底域渗漏**：「描述与评价」（形容词/副词兜底）与「方法与行动」（动词兜底）里混着名词。

## 二、判据与纪律

判据只有一句，与初中、四六级那套一致：

> **把这一关的词随机摆在一起，玩家会不会觉得「它们是一伙的」？**

纪律（写死在给子代理的 `SPEC-hs.md` 里）：

1. **只标确实不搭的**，每册 10~45 条；**绝不为凑数而标**；
2. **零丢失**：一个词都不能凭空消失（词数必须一条不差）；
3. **不许自创域名**——去向必须是那 41 个在用的域之一或既有特殊主题；
   ⚠️ 高中另有 **11 个域**因「11 册总量 < 33 词、必然有册不足 3 词」已被整体并入近邻域，
   它们**在高中不存在**（`学习用品`/`家庭成员`/`日常起居与家务`/`英雄与传奇`/`问候与应答`/
   `厨房与餐具`/`水果与蔬菜`/`节日与庆典`/`天气与季节`/`音乐与乐器`/`运动与比赛`）；
4. 同一册内**中文不得重复**（「同义表达：」类主题豁免）。

## 三、方法：11 个并行子代理 + 第二轮补位

1. 用切关复刻把每册逐关摊平，生成 11 份校对材料（`pep-h-1.md` ~ `pep-h-11.md`，每行就是线上棋盘那一关）；
2. **11 个子代理并行**，一册一个，逐关读、逐条标，输出 `flag-<册>.tsv`；
3. 收集 **197 条**标记，逐条核对「现属域与产物一致」（197/197 全等，`NF==7`）；
4. 先模拟全部移动，暴露「目标域掉到 3 词以下」的陷阱 —— **79 条域错位里只有 20 条直接可行**；
5. **第二轮：11 个子代理再做补位可行性核查** —— 对每个危险目标域，从该册词表里找**真正属于该域**的词
   一并移过去（凑到 ≥3 词），找不到就如实说「无法补位」。**11 个域里只救回 8 个**，其余确实没有第 3 个同类词；
6. 按「(册, 目标域) 分组，合计 ≥3 词才整组采纳」的规则写回域表与词库。
