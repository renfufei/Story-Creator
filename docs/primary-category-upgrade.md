## 一、方法：把小学也纳入「tsv 唯一真相」

小学此前**没有独立语义域表**——主题直接躺在 `pep-words.json` 里（`build_pep_words.py` 是历史一次性脚本，
只从 JSON 读回主题）。为了让小学与初/高中同一套机制、后续可复现可审计，本轮：

1. **新建 `src/test/resources/learn/pep-words-source/primary-semantic-domains.tsv`**，作为小学唯一真相。
   格式与初/高中一致：`主题名<TAB>英文@册id,...`。特殊主题
   （`常用功能词（代词/冠词/助动词）` / `不规则变化` / `同义表达：*`）**不入表**，由构建脚本原样保留。
2. **`build_semantic_themes.py` 新增 `primary` 学段**（`--stage primary` / `all`），只动目标学段的册。
3. **域序用「稳定拓扑排序」求出**：把「每册主题按课本单元顺序」当作约束，求一个全局域序，
   使**每册的主题相对顺序与改动前完全一致**。生成脚本会逐册断言 `期望 == 实得`，不一致就拒绝出表。
   （小学主题是课本单元顺序，有教学意义，不能像初/高中那样重排。）

## 六、有意**不改**的（C 档，附理由）

不为凑数扭曲语义是本项目的红线，以下均**保留原位**：

- **三上「日常用语」(7)**：`no` `your` `OK` `mum` `school` `funny` `brother` 是兜底筐；本册无家庭成员 / 功能词 / 场所主题可去。
- **三下「描述人与动物」里的 `giraffe`**：主题名本就含「动物」，课本也是「描述动物（长颈鹿很高/很矮）」，**语境正确**。
- **四上「朋友与外貌」里的 `hair` / `shoe` / `hat` / `puppy`**：本册没有身体部位 / 服装 / 动物主题，且「外貌」确实涵盖发型衣着。
- **四下「天气」里的 `outside` / `be careful` / `how about ...`**：本册无其它家（1 词也凑不成域）。
- **四下「课程与三餐」**：混着「课」与「餐」，主题名如实，不动。
- **五上「季节与植物」里的 `pink` / `snow` / `snowman`**：本册无颜色 / 天气主题；`snow`/`snowman` 与「季节（冬）」语境相容。
- **五上「居住与动物」里的 `mouse` / `rabbit`**：本册只有 **2 个**真正的动物词，凑不成 3 词关，**拒绝拿非动物词硬凑**。
- **五下「寻找与发现」里的 `bunny` / `kitten` / `fur`**：只有 2 个真正的动物（`fur` 是动物皮毛而非动物），同上不成关。
- **六上「自然与动物」** 与 **六下「变化与感受」**：内容偏杂，但本册无更合适的容器，且属课本 Recycle 单元。
- **同形异义**（`orange` 颜色/水果、`hot` 天气/辣、`fish` 鱼/钓鱼、`chicken` 鸡肉/鸡）分别立项，**正常**，不动。
