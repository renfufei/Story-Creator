数独怎么玩

目标

把空格填满，让每一行、每一列都恰好出现一次 1~N；带宫格的尺寸还要求每个宫也恰好一次。 题目保证只有一个解，所以不需要猜，慢慢推都能推出来。

尺寸与规则

4×4 / 6×6 / 8×8 / 9×9 是标准数独：除行列外还有粗线划出的宫 （4×4 是 2×2 宫，6×6 是 2 行 3 列，8×8 是 2 行 4 列，9×9 是 3×3 宫）。

3×3 / 5×5 / 7×7 是拉丁方：尺寸是素数，切不出等宽的宫格， 所以只要求行列不重复。规则更简单，但题目给的数字更少，一样需要推理。

工具

笔记：把数字记成格子角落的小候选数，用来做排除法。
提示：直接帮你填对一个格子。每局的提示次数按棋盘尺寸和难度自动分配 —— 格子越多、难度越高给得越多（3×3 只有 1 次，9×9 困难最多 10 次），用掉几次会记进成绩。
检查：标出与答案不符的格子，每局 3 次 —— 留到实在卡住时再用。

键盘

1~9 填数 · 0 或 ⌫ 擦除 · 方向键移动选中格 · N 切笔记 · H 提示 · Ctrl+Z 撤销 · Esc 取消选中

存档

每一步都会存在本机浏览器里：关掉页面、换尺寸再换回来都还在， 点【新局】才会换成新题。
